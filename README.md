# ⚡ Pokémon: I Choose You! 🍃🔥💧

A fun, kid-friendly mobile web Pokémon game built for a 6-year-old Pokémon Trainer and his dad!

---

## 🎮 Game Features
- **🌾 Tall Grass Exploration:** Rustle through tall grass patches to find wild Pokémon, hidden PokéCoins, and potions!
- **⚔️ Turn-Based Battles:** Battle wild Pokémon and watch your HP! Use potions to heal, or unleash signature elemental moves!
- **🔴 Epic Catch Animation:** Throw the Pokéball in an arc, beam the Pokémon inside with glowing red energy, watch the ball fall, bounce, wobble 3 times, and lock with confetti!
- **🚨 Team Rocket Battles & Village Jail:** High stakes battles against Team Rocket! If you win, earn 200 coins and send them to jail! If they win, they steal a random Pokémon!
- **🏡 Build Your Own Pokémon House:** Earn coins, buy wood, bricks, roof tiles, and cushions at the Builder Market, and hammer your house together stage by stage!
- **📖 Sticker Pokédex:** Track all caught Pokémon and see your collection grow!
- **Synthesized 8-Bit Web Audio:** Crisp retro sound effects running directly in browser without loading bulky audio files.
- **PWA Mobile-Ready:** Fullscreen portrait experience with zero browser address bars when added to your phone's home screen.

---

## 🚀 How to Run Locally

### 1. Start the Dev Server
```bash
npm run dev
```

### 2. Play on Your Phone (Same Wi-Fi)
Vite runs with `--host` enabled. Look at the terminal output for the **Network URL** (for example: `http://192.168.0.92:5173`).
- Open Safari (iOS) or Chrome (Android) on your phone.
- Type that URL or scan its QR code.
- Tap **"Share" -> "Add to Home Screen"** to play in beautiful fullscreen!
